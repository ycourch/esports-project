# EsportsProject

This was a project created for the IBM Watsonx Hackathon: AI Skillsbuild program. This project was created by the WGU WinTech team to address the issue of eSports broadcasters struggling to maintain consistent viewership. Our team created an AI agent to help broadcasters stay up to date on tournaments and past matches to provide more contextual information necessary for compelling storytelling to increase viewer engagement. This project was hosted using AWS to create a working link for project submission.
